Abstract

Existing lifelog-based sleep prediction methods use multimodal smartphone and wearable data for daily sleep prediction but mainly rely on daily observations or short-term statistics, limiting their ability to capture long-term states. Furthermore, they often encode long-term states and day-specific variations in a single representation, making it difficult to distinguish their respective effects on sleep outcomes. To address these limitations, we propose SOLAR, a stepwise anchor-and-refine framework. We first construct long-term personalized features from accumulated behavioral history to capture each individual's long-term states. The framework then generates target-specific anchors and refines them using day-specific sensor states, variations from personal long-term states, and temporal-neighbor history. Experimental results show that SOLAR outperforms other baseline methods.

The SOLAR Framework

Separate what is typical for a person from what changed on a particular day.

STEP 1

Personalized temporal anchor

Construct a target-specific baseline from accumulated personal history, calendar patterns, and long-term sensor states. Combine out-of-fold prediction sources with target-wise stacking.

STEP 2

Day-specific residual refinement

Predict the variation left unexplained by the anchor using current sensor observations and deviations from the individual's usual state. A controlled residual update preserves personal context.

STEP 3

History-aware refinement

Use temporal-neighbor information from the same participant. Apply refinement separately for each target when it improves validation performance.

Why Long-Term History Matters

Accumulated personal patterns complement recent observations, especially for objective sleep indicators.

The useful time scale depends on the target

Longer history captures signals that daily observations miss. For sleep onset latency (S3), absolute correlation with heart rate increases from 0.19 → 0.24 → 0.32 across 1-day, 3-day, and 28-day windows.

The effect varies across targets: longer history is not consistently better for every outcome.

Personal states appear in the explanations

SHAP analysis shows higher attribution per long-term feature across all four objective targets (S1–S4). Short-term features still account for a larger total contribution, in part because there are many more of them.

LIME provides a complementary view: long-term state features appear among the most salient individual features for several targets.
