SOLAR / Sleep prediction from multimodal lifelog data

Long-term anchors, target-day corrections.

SOLAR predicts sleep-related targets by first estimating each participant's personal baseline, then refining that anchor with day-specific sensor states and temporal-neighbor history.

Abstract

Daily sleep data needs personal context.

Wearables and smartphones produce dense behavioral and physiological traces, but a target-day value alone is not enough. SOLAR explicitly separates stable individual state from temporary daily variation.

The framework constructs long-term personalized features from accumulated behavioral history, including rolling windows, cumulative statistics, same-weekday patterns, and missingness history.

It then generates target-specific anchors and refines them using target-day sensor states, deviations from personal long-term states, and temporal-neighbor records from the same participant.

Takeaways

What the page should make clear.

SOLAR is not just another tabular ensemble. The contribution is the modeling order: learn the participant's long-term anchor, then refine it with target-day evidence and target-specific temporal history. 

features = short_term + long_term + short_long_contrast + participant_history
anchor   = stack_targetwise(history_priors, calendar_priors, long_term_sensor_sources)
residual = learn_target_day_correction(anchor, personalized_day_state)
output   = history_aware_refine(anchor + residual, temporal_neighbors)
